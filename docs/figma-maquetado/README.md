# Maquetado Figma - El Circulo Futbol

Este paquete resume el proyecto como una maqueta lista para presentar en Figma.

## Archivo principal

- `el-circulo-futbol-maquetado.svg`

Para usarlo en Figma:

1. Abrir Figma.
2. Crear un archivo nuevo.
3. Arrastrar `el-circulo-futbol-maquetado.svg` al canvas.
4. Si queres editar por partes, desagrupar el SVG y convertir las secciones en frames.

## Pantallas incluidas

- Landing comercial.
- Login.
- Listado de canchas.
- Reserva de cancha.
- Mis reservas.
- Panel admin.
- Usuarios.
- Reportes.
- Sistema visual base.

## Enfoque de presentacion

La maqueta esta pensada como producto real, no como consigna academica. El discurso recomendado:

> El Circulo Futbol es una plataforma web para reservar canchas de futbol por momentos del dia. Los clientes pueden ver canchas, reservar y consultar su historial. Los administradores gestionan canchas, reservas, clientes y reportes desde un panel operativo.

## Componentes clave

- Navbar con marca, rol y acciones principales.
- Hero con cancha como recurso visual.
- Cards de canchas clickeables.
- Formularios compactos con validacion.
- Calendario operativo para admin.
- Lista paginada de reservas.
- Toasts unificados abajo a la derecha.
- Badges de estado para reservas, usuarios y pagos.

## Flujo para explicar

1. Cliente entra a la landing.
2. Ve canchas disponibles.
3. Selecciona cancha, fecha y momento.
4. Crea una reserva pendiente de pago.
5. Consulta sus reservas e historial.
6. Admin gestiona canchas, clientes y reservas.
7. Super admin administra usuarios y permisos.
8. Admin y super admin consultan reportes.
